# MEDIA-00 — единый валидатор SVG

Реализовано 20 октября 2026 в worktree бэкенда `codex/be-01-foundation`
от `ab6b105`, после BE-01. Область изменений этой карточки — только
`apps/api/internal/platform/svg/**`. Общие зависимости, OpenAPI 0.13.0,
SVG-профиль 1.0.0, миграции, seed, исходные изображения и веб не менялись.

## Интерфейс для следующих модулей

```go
normalized, err := svg.Normalize(input)
if err != nil {
    return err
}
// Только здесь сохранять normalized и менять статус/revision в общей транзакции.
```

[Normalize](svg.go) принимает SVG-строку и возвращает весь проверенный документ.
При любом отказе строка результата пустая. Ошибка — общий `*fault.Error`:
413 / PAYLOAD_TOO_LARGE для превышения 131072 байт UTF-8 до **или после**
нормализации; 422 / VALIDATION_ERROR с `/svg` для XML, графики и сложности.
Текст ошибки не содержит исходную загрузку, адрес ресурса или внутренний XML-log.

Это один пакет для будущих MEDIA-01A/01B/01F; личные загрузки/модерация,
сохранение в БД, HTTP-обработчики, публичные URL и публикация готовой статики
в этой карточке не реализуются. JSON-лимит 1 МиБ остаётся в HTTP-инфраструктуре.
Проверка ничего не записывает и не меняет прежний SVG/статус/версию.

## Разбор и нормализация

- Стандартный `encoding/xml` закреплённого Go 1.27.2: `Decoder.Token`, Strict,
  без Entity/CharsetReader, без загрузки внешних ресурсов.
- Исходные байты/UTF-8, ровно один SVG-корень с viewBox, пространства имён,
  уникальные атрибуты и их allowlist, контекст вложенности, отсутствие активной
  графики/текста/CSS/внешних ссылок. После корня — только XML-пробел.
- [Числа и контуры](numbers.go): полный разбор команд/арности path, неявные
  повторы и пары M, флаги дуги отдельными 0/1, конечность/диапазон и общий бюджет.
- [Атрибуты](attributes.go): геометрия, цвета, локальные ссылки на существующие
  уникальные градиенты, проценты, перечисления, points/dasharray, преобразования
  с проверкой арности/масштаба/skew. Forward reference разрешён.
- Общие счётчики глубины/элементов/чисел/сегментов/градиентов/stop, пределы
  атрибутов/значений, points, ID, viewport и transform. Лимиты включительны.
- Без «удалить опасное и принять остальное»: неподдерживаемый файл целиком
  отклоняется. Отбрасываются только комментарии, декларация и пустой текст.
- Атрибуты сортируются; hex-цвета приводятся к нижнему регистру; сохраняется
  последовательность графических элементов, координаты и грамматика контуров.
  Сериализация через XML Encoder, с единственным default xmlns на корне.
  Повторная нормализация байт-в-байт одинакова; размер вывода ограничен писателем.

Источник ограничений — [профиль проекта](../../../../../docs/architecture/svg-profile.md)
и [машинный JSON](../../../../../packages/contracts/svg-policy.json), а не новый
независимый формат. Проверка parity сверяет версию, namespace, все численные
лимиты, элементы и атрибуты. Парсер чисел следует грамматике SVG 2: после точки
нужны цифры; `1.` отклоняется. Неполные команды, лишние запятые и чужие единицы
не превращаются в частично отрисованный контур.

Технические источники: [encoding/xml](https://pkg.go.dev/encoding/xml),
[SVG path grammar](https://www.w3.org/TR/SVG2/paths.html),
[SVG types](https://www.w3.org/TR/SVG2/types.html). Численные бюджеты заданы проектом.

## Проверка готовых файлов сборки

Команда [checksvg](cmd/checksvg/main.go) использует тот же Normalize, читает
не более MaxBytes+1 байта каждого файла, не меняет исходники и возвращает
ненулевой код при ошибке. Из корня репозитория:

```bash
go -C apps/api run ./internal/platform/svg/cmd/checksvg \
  ../../packages/contracts/avatar-presets/ryadom-companion.svg \
  ../../design/assets/event-covers/ryadom-meeting-point.svg
```

Это узкая проверка SVG-файлов. Проверка manifest/выбор ID/URL принадлежат BE-02,
включение готовой статики в веб-образ и обязательная регистрация — MEDIA-01F.
Встраивание этой команды в продуктовую сборку остаётся за координатором.

## Выполненные проверки

- Все **35** общих [conformance-случаев](../../../../../packages/contracts/examples/svg-cases.json),
  включая настоящие аватар/фон, 131072/131073 байта и многобайтный UTF-8.
- Границы глубины, элементов, числа/значения атрибутов, implicit path-сегментов
  в нескольких path, общего бюджета чисел (включая компактные флаги дуг),
  пар points, transform, gradient, stop в нескольких градиентах, ID,
  dasharray, viewport/координат/opacity/scale/skew; валидная верхняя граница
  и превышение. Для 32 атрибутов allowlist не позволяет столько уникальных
  имён на элементе; дубли/неизвестные отклоняются и на этой границе.
- Отдельно нормализованный размер: исходник помещается в предел, а развёртывание
  пустого элемента превышает его на один байт — 413 и пустой результат.
- Неверные namespace, XML, декларации/директивы/entities, текст, вложенность,
  активная графика, цвета/ссылки, грамматика path/transform, повторная сериализация.
- CLI: настоящий файл, опасный/слишком большой/недоступный, смешанный набор,
  отсутствие ложного OK для отказа и сохранность исходника.
- Go fuzzing: 20 секунд, два worker, **105154** входа без сбоя; инварианты
  пустого результата при отказе, безопасной ошибки и стабильного повторного разбора.
- Независимый рендер ImageMagick/librsvg: исходник и нормализованный результат
  аватара 256×256, фона 1600×900, локального градиента и сложной геометрии
  совпали по всем RGBA-байтам. Сводное изображение просмотрено визуально.
- Общий Go-набор с race detector в Docker/Compose, включая настоящие SQL-тесты
  BE-01/DB-01/DB-02 и AUTH-01, прошёл. Локальные go vet и проверки репозитория
  также прошли. Продуктовая контейнеризация/постоянный том — ещё OPS-01.

Из apps/api:

```bash
go test -race ./internal/platform/svg/...
go test -run '^$' -fuzz '^FuzzNormalize$' -fuzztime=20s -parallel=2 ./internal/platform/svg
go vet ./...
```

Дополнительные образцы для независимого рендера можно выгрузить только в
явно указанный тестовый каталог; обычные тесты их не создают:

```bash
RYADOM_SVG_RENDER_DIR=/tmp/ryadom-svg-render go test -run TestRenderingSamples ./internal/platform/svg
```

Общая контейнерная проверка из корня, без портов/постоянного тома:

```bash
docker build --network=host -f apps/api/internal/platform/svg/testdata/Dockerfile -t ryadom-media00-go-check .
docker compose -p ryadom-media00 -f compose.foundation.yaml -f apps/api/db/migrations/testdata/compose.yaml -f apps/api/db/seed/testdata/compose.yaml -f apps/api/internal/platform/svg/testdata/compose.yaml up -d --wait db
docker compose -p ryadom-media00 -f compose.foundation.yaml -f apps/api/db/migrations/testdata/compose.yaml -f apps/api/db/seed/testdata/compose.yaml -f apps/api/internal/platform/svg/testdata/compose.yaml run --rm --no-deps go-check go test -race -count=1 ./...
docker compose -p ryadom-media00 -f compose.foundation.yaml -f apps/api/db/migrations/testdata/compose.yaml -f apps/api/db/seed/testdata/compose.yaml -f apps/api/internal/platform/svg/testdata/compose.yaml down
```

Host-сеть нужна только сборщику из-за DNS этой среды. Тестовые контейнеры
используют отдельную Compose-сеть. Версии Go/PostgreSQL/goose прежние, новых
зависимостей/сервисов нет. Файлы в случайных тестовых схемах не затрагивают общую БД.

## Передача

Результат для координатора: общий Normalize + безопасные ошибки и явная
проверка файлов сборки готовы к подключению. OPS-01/BE-02 и MEDIA-01F ещё
должны пройти свои зависимости и общую приёмку. Личные SVG/фон пока нельзя
загрузить через API; работающий пакет не объявляется готовой функцией продукта.
Очередь/CONTEXT/manifest меняет их владелец по этому отчёту. Коммита/push,
публикации или обращения к серверу пользователя не было.
