# BE-04 — создание и публикация встречи

Назначенный пакет BE-P1, база e7d6958, ветка codex/be-03-event-reads. Пользователь
разрешил последовательные BE-04 → BE-05 → BE-06 и самостоятельное подключение.

createEvent зарегистрирована самим Service.Register: существующее подключение
модуля в main уже включает маршрут. PERSONAL берёт текущий аккаунт; ORGANIZATION
проверяет владение и APPROVED под замками организации/заявки. Чужая — 404, своя
без допуска — 409. Дата строго будущая по актуальным часам API, повторно после
ожидания замков; IANA-зона, trim/длины и пустые строки проверяются. Выдаётся
канонический PublishedEventDetail автора только после commit (201).

Новый спорт: NFC, свёртка Unicode-пробелов, lowercase для уникальности; новое
PENDING-направление и встреча в одной транзакции. ON CONFLICT DO NOTHING и свежее
чтение FOR SHARE разрешают конкуренцию; существующие решения/даты/автор сохраняются.
Известные PENDING/REJECTED ID допустимы. Имя при повторном использовании не меняется.
Ретраев POST/новой независимой транспортной схемы нет.

Файлы: events/create.go, events/events.go, activitytypes/resolve.go, относящиеся
SQL activity_types.sql/events.sql и sqlc-производные, events/create_test.go.
Миграции, go.mod/go.sum, OpenAPI 0.13.0/Go/TS DTO и фронтенд не менялись.

`go test -race -count=1 -v ./internal/modules/events` — PASS (20.126s), включая
чтения BE-03 и новые сценарии создания. Проверены S1 на HTTP с PostgreSQL:
создать → каталог → чтение другой сессией, новое направление/приватный review;
