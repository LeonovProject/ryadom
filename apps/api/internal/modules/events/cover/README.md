# MEDIA-01B и передача серверного MEDIA-пакета

База пакета: a65d1c9 (QA-01). MEDIA-01A: 9cc4287. Ветка
codex/be-03-event-reads; единственный BACKEND/DATABASE. Следующая фиксация содержит
MEDIA-01B и итоговую проверку обоих модулей; объединение выполняет координатор.

Три операции существующего OpenAPI 0.13.0 подключены в cmd/api/main.go:
setEventCover/deleteEventCover/getEventCover. Нормализованный SVG хранится в
существующем events.cover_svg. Замок events FOR UPDATE общий со снятием встречи:
менять/сбрасывать фон может только ответственный автор PUBLISHED, включая после
начала. Повтор установки/сброса не переписывает updated_at при том же содержимом.
Чтение использует тот же SQL-предикат, что getEvent: после снятия посторонним 404,
автор/ADMIN/имеющий участие сохраняют доступ. Ошибки XML/размера/commit не меняют
прежний фон. Изображения: image/svg+xml, nosniff, CSP sandbox, private/no-store.

Схема/миграции, OpenAPI/DTO, зависимости, seed, Compose, веб и общий preview не
менялись. Пользовательские SVG проверяет единственный MEDIA-00. Демофон не добавлен
в DB-02 seed: это отдельное согласование по DEC-22; действующий seed оставляет NULL.
DEC-27 и незакоммиченная подготовка HTTP-развёртывания координатора не переносились
из общей рабочей копии. Наши обработчики не зависят от режима HTTP/HTTPS.
