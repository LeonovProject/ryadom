# BE-11

Подключены reportEvent/reportMessage, adminGetMessage/adminRestoreMessage,
adminDismissEventReports/adminDismissMessageReports. Подача не требует участия,
не скрывает контент, не принимает причину. Порядок: доступ/публикация, запрет
своей цели, существующая квитанция, видимость новой цели. Повторы закрытых жалоб
не открывают их. Автор встречи вправе жаловаться на чужое сообщение.

Все переходы используют event → message и общий барьер. Непустой разбор
проверяет reportsRevision, закрывает только свою группу и увеличивает версию;
пустой — безопасный повтор. Скрытие/снятие переиспользуют прежние BE-08/09.
Восстановление сохраняет hiddenAt/By, исходный текст/ID/порядок, увеличивает
moderationRevision и не открывает жалобы/публикацию.

TestP3ReportsAndRestore на PostgreSQL с race detector — PASS (2.979 s):
параллельная подача одной жалобы, обе цели, свои цели/права, разбор и новые
жалобы против старой версии, закрытые повторы при HIDDEN, скрытие/восстановление,
старая команда скрытия и восстановление внутри UNPUBLISHED. DTO сверены со схемой.
SQL/sqlc и main.go подключены. Контракт, схема БД, зависимости не менялись.
Общая HTTPS-проверка и отчёт — после BE-12; общий регресс оставлен интегратору.
