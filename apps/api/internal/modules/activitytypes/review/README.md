# BE-10

От интеграционной базы c7c04b1. Подключены четыре операции модерации направлений:
список/чтение, разовое решение, переименование любого состояния и seed.
NormalizeName общий с созданием встреч: NFC, пробелы, регистр и лимиты.
expectedName защищает изменения; совпавший результат возвращается без записи.
UNIQUE-коллизия даёт ACTIVITY_TYPE_NAME_CONFLICT с полным откатом. Число встреч
считается по всем публикациям. Права, состояния/встречи и ID не меняются.

Адресный PostgreSQL/HTTP-router тест TestP3ActivityReview с race detector — PASS
(2.987 s): обе ветки, коллизия и откат, устаревшая форма/повтор, два одновременных
переименования, seed и привязка курсора. Код подключён в main.go.

и общий отчёт — после всего BE-P3; общий регресс оставлен интегратору по просьбе
пользователя. Следующие BE-11/12 выполняются в этой ветке без промежуточного merge.
