# SQL BE-02

Единый владелец DATABASE ведёт accounts.sql, account_avatars.sql, sessions.sql
и generated internal/db. Схема — прежняя DB-01, запросы работают только через
переданную pgx.Tx общего Runner, без отдельного соединения/commit.
В accounts.sql находятся также узкие чтения владения для общего auth-guard;
это не обработчики событий/организаций. Дальнейшие модули расширяют свои SQL
через того же владельца, не создают независимые запросы в обработчиках.

Генерация из корня (UID/GID соответствуют владельцу рабочей копии):

```bash
docker run --rm --user "$(id -u):$(id -g)" \
  -v "$(pwd)/apps/api:/src" -w /src/db \
  sqlc/sqlc:1.31.1@sha256:70f53171d27b2424e9358869975455a6e955a5aa8e58a998a270a6e34e525537 generate
```

При сборке API те же запросы заново генерируются в отдельной стадии и
сравниваются с сохранённым пакетом; расхождение останавливает сборку.
Источники и результаты не редактируются параллельно разными владельцами.
