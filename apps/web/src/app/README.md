## Результат

- `App.tsx`, `AppShell.tsx`, `routes.ts`: React Router и Query Provider,
  адаптивная навигация, 21 маршрут из карты экранов, 404 и обработка ошибки.
  Каждый продуктовый маршрут пока явно показывает «Раздел готовится».
  SCR-19 представлен общими состояниями, отдельного URL для него нет.
- `../shared/ui/`: кнопки/ссылки, поля с подсказкой и ошибкой, Radix Dialog,
  состояния загрузки/пустоты/ошибки/недоступности, отдельные типизированные
  статусы участия, публикации и допуска организации.
- `../shared/api/`: общий клиент из `@ryadom/api-client` и QueryClient.
  DTO только из сгенерированного OpenAPI, cookie same-origin, автоматические
  повторы запросов и мутаций отключены. Запросы к API пока не отправляются.
  Сессионные проверки/очистка личного кеша относятся к FE-02.
- `../shared/lib/event-time.ts`: дата/время начала в IANA-зоне встречи,
  год и GMT-смещение на её дату, включая сезонное время и дробные смещения.
  Тип входа взят из PublishedEventSummary: у недоступной публикации этих полей нет.
- `../shared/styles/`: исходные CSS-токены импортируются из брендбука;
  шрифты с лицензиями скопированы из согласованного локального макета и входят
  в сборку Vite. Внешний CDN не нужен, исходники брендбука не менялись.

В режиме разработки `/dev/ui` показывает интерактивные примеры компонентов;
ссылка на них находится в подвале. В производственной сборке маршрут и галерея
отсутствуют. Галерея не имитирует успешную бизнес-операцию.

## Просмотр и воспроизведение проверок

Команды из корня репозитория, с уже установленными зависимостями BASE-01:

```bash
pnpm --filter @ryadom/web dev --port 4173 --strictPort
# Открыть http://127.0.0.1:4173/dev/ui
```

Браузерный тест запускает свой сервер на отдельном порту 4175.
Он также проверяет FE-02 на HTTP-фикстурах; просмотр на 4173 можно оставить открытым.

```bash
pnpm typecheck
pnpm build
pnpm exec vitest run apps/web/src/shared
pnpm exec playwright test --config apps/web/src/app/tests/playwright.config.ts
python3 scripts/check_repository.py
python3 scripts/check_handoff.py
git diff --check
docker compose -f compose.foundation.yaml build web-check
```

Playwright использует установленный Chromium. При наличии системного Chrome
можно указать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/google-chrome`
перед командой теста. Снимки/диагностика сохраняются в игнорируемом
`.artifacts/fe-01/`. Браузер запускается с зоной America/Los_Angeles, пример
встречи сохраняет 07:00 GMT+7.
