## Исправления

- Ссылка с одним `dateFrom` означает нижнюю границу без последнего дня.
  Раньше изменение только текста/города незаметно добавляло `dateTo` на
  следующий день. Теперь поиск сохраняет исходные календарные границы,
  включая верхнюю без нижней и граничную `0001-01-01`. Правило одного дня
  применяется при явном изменении полей дат. Подпись поясняет диапазон из ссылки;
  календарные значения по-прежнему не проходят через зону устройства.
- Сохраняются from/to, направление, режим, организатор и город; при изменении
  условий старый курсор не передаётся. История браузера возвращает значения
  формы. На телефоне дополнительные фильтры из ссылки сразу раскрыты,
  применение их не сворачивает; ручной переключатель сохранён.
- UUID направления сравнивается без учёта регистра: APPROVED из каталога
  не становится «Направлением из ссылки» из-за uppercase. При ошибке обновления
  справочника прежние варианты скрыты, выбранный ID сохранён явно как вариант
  из ссылки. Главная также не показывает устаревшие быстрые ссылки при сбое.
- Публичная выдача перечитывается при возврате во вкладку, даже в пределах
  30-секундной свежести кеша. Ошибка перечитывания скрывает старые карточки:
  доступность публикации могла измениться. Она отличается от пустого результата.
  Ошибка следующей страницы сохраняет уже загруженные карточки, с одним
  действием повторной загрузки; INVALID_CURSOR позволяет начать заново.
- Сравнение идентичностей между/внутри страниц не зависит от регистра UUID.
  Новая запись заменяет карточку целиком без склейки полей/дублей и без изменения
  серверного порядка. UNPUBLISHED, ошибочно пришедший в публичном списке,
  отклоняет ответ до показа его заголовка/адреса.
- После успешного «Показать ещё» фокус переходит к ссылке первой новой встречи.
  Если человек уже перешёл к фильтру, фокус не перехватывается. При смене
  условий запоздалый ответ старого поиска не заменяет новую выдачу.
- На главной ошибки поиска связаны с конкретными полями, фокус у первого
  неверного поля, ввод сохранён. Есть компактная кнопка обновления ближайших
  встреч. Возврат в видимую вкладку/окно обновляет абсолютную границу `from`;
  ссылки каталога/направлений используют тот же момент. Каталог сохраняет
  прежний `from` для области страниц и возврата. Личная главная остаётся
  местом подключения FE-08, без фиктивных участий или ложной пустоты.
- Заголовок выдачи «Встречи по выбранным условиям» соответствует явному from
  из ссылки, который может быть в прошлом. Дата каждой встречи остаётся
  в её зоне с GMT; дата абсолютной границы подписана UTC.

## Дополнительный проход: возврат к каталогу

Поручение «Продолжи», 20 октября 2026; продолжение собственного `8332364`
от той же общей базы `ee620a7`. Ни нового общего SHA, ни готовой передачи
BE-03 в main на момент начала нет. Выполнена ещё одна ограниченная часть FE-03,
без перехода к чужим карточкам и без изменения shared или EventPage.tsx.

- Обычный переход по названию или «Открыть встречу» запоминает ID карточки,
  её смещение относительно viewport, использованную ссылку, точный URL фильтров
  и номер сессионной границы. Открытие с модификаторами в другую вкладку
  не включает восстановление исходной вкладки.
- После ссылки «К найденным встречам» или Back браузера сохраняются фильтры
  и загруженная цепочка выдачи. Положение и фокус восстанавливаются только
  после успешного перечитывания страниц. Восстановление относительно карточки,
  а не абсолютных пикселей документа, выдерживает изменение высоты более
  ранних карточек. Вход с клавиатуры возвращает видимое кольцо фокуса.
- Если карточка исчезла или выдача стала пустой, фокус/прокрутка переходят к
  заголовку свежих результатов. Старые закрытые сведения не возвращаются.
  При ошибке перечитывания карточки остаются скрыты; повтор работает как
  обычная загрузка, без обхода текущих прав или старых курсоров.
- Если человек уже начал менять фильтр, завершение чтения не забирает фокус.
  Смена условий/сессии отменяет прежнюю позицию; новая сессия не запрашивает
  старые дополнительные страницы ради поиска выбранного ID.
- Память ограничена одной позицией в модуле вкладки. Она расходуется один раз,
  не записывается в localStorage/sessionStorage/URL и исчезает при перезагрузке
  документа. Карточки, ответы API, курсоры, Me, пароли и JWT там не хранятся.
  Глобальная политика history.scrollRestoration не меняется.
