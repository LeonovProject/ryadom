## Изменения

Все файлы находятся в `apps/web/src/features/events/create/`:

- `first-meeting.ts`: вопросы, фиксированный порядок, обычный текст, лимиты
  ответов 600/600/400/600 и итоговых условий 4000 Unicode code points.
- `FirstMeetingHelper.tsx`, `create.module.css`: исходно закрытый блок,
  необязательные ответы, предпросмотр, связанные ошибки, явное добавление,
  уведомление и фокус условий. При добавлении ручной текст сохраняется;
  ответы очищаются. Повторное нажатие не дублирует вставку.
- `CreateEventPage.tsx`: хранение ответов между шагами, явный выбор перед
  проверкой, в том числе при возврате из сводки через первый шаг. Удаление
  ответов сохраняет ручные условия и выполняет обычную валидацию.
  Помощник входит в существующий disabled fieldset; запрет повтора при
  неизвестном результате публикации сохранён.
- `draft.tsx`: необязательный `firstMeeting` рядом с `values`:
  `{ preparation: string, equipment: string, recognition: string, welcome: string }`.
  Старый черновик без этого поля открывается с пустыми ответами. Только память
  вкладки и прежние правила ownerId/сессии, без storage.
- `EventSteps.tsx`: подсказка места «Укажи адрес, точку сбора и ориентир».
- `tests/first-meeting.test.ts`, `tests/first-meeting.spec.ts`,
  `tests/first-meeting-runtime.cjs`: адресная проверка нового поведения.

`EventValues`, `eventInput`, API 0.13.0, зависимости, БД и общие конфигурации
не менялись. В HTTP передаётся только прежний `conditions`, например:

```text
Участие бесплатное.

Подготовка и темп: Без опыта, спокойный темп
Что взять с собой: Вода и удобная обувь
Как узнать организатора: Анна с красной лентой
В начале встречи: Знакомство и объяснение <правил>
```

HTML-подобный текст отображается буквально. Примеры полей не являются значениями.
