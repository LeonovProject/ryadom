# Веб

Прочитайте ../../docs/development/handoff/frontend.md. Старый HTML-макет не задаёт
актуальный вход, личную главную и новые административные пути. Типы — из общего
API-клиента, оформление — из брендбука. src/** принадлежит FRONTEND по карточкам;
package.json/lock/Vite/контейнеры и общая интеграция — COORDINATOR.
Проверки из корня: pnpm typecheck, pnpm build; для реальных сценариев нужна
контейнерная интеграция с сервером. Временный main.tsx заменяется в FE-01.

По принятому пакетному процессу прочитайте
../../docs/development/handoff/work-packets.md. Единственный FRONTEND сам
подключает экраны/навигацию/общие ключи кеша в рамках своего пакета. Координатор
не меняет эти файлы параллельно; зависимости/контракты/Compose остаются общими.
Следующая карточка пакета не требует отдельного назначения/merge; итоговая
передача содержит проверенный SHA и статус каждой карточки.
