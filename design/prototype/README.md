# Рядом — дизайн-прототип 0.1

Локальный интерактивный макет для обсуждения внешнего вида и переходов.
Все люди, организации, места встреч и события — вымышленные примеры.
Это не реализация бизнес-логики из постановки: API, БД и серверной авторизации нет.
Предложенный технический стек остаётся не утверждённым.

## Открыть

Откройте [index.html](index.html) в обычном браузере. Установка зависимостей не нужна.
Сохраните структуру каталогов репозитория: CSS использует исходные
[токены брендбука](../../brandbook/assets/tokens.css). Шрифты находятся локально.

Для просмотра через HTTP из корня репозитория можно запустить:

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Затем откройте [локальный прототип](http://127.0.0.1:4173/design/prototype/).
Для остановки сервера — Ctrl+C. Это просмотр статических файлов, не команда
запуска будущего продукта. В этой задаче сервер проверялся: HTML и сценарии
отдавались с HTTP 200; после проверки временный сервер остановлен.

## Что можно посмотреть

В верхней панели «Дизайн 01» выбираются шесть основных экранов:

| Экран | Адрес внутри макета | Содержимое |
| --- | --- | --- |
| Главная | `#/` | Hero, поиск, направления, встречи, объяснение пути |
| Каталог | `#/events` | Поиск, фильтры, карточки, пустая выдача |
| Мероприятие | `#/events/run` | Условия, запись, автор, обсуждение |
| Профиль человека | `#/people/anna` | Имя, направления лично организуемых встреч, события |
| Организация | `#/organizations/temp` | Сообщество, интересы, допуск и опубликованные встречи |
| Создание | `#/events/new` | Три шага, своё направление, режим, предпросмотр |

Дополнительно есть личный кабинет `#/me`, свои встречи `#/me/events` и
управление составом `#/events/tennis/manage` для автора. Это вспомогательные
экраны для проверки переходов первой версии, не весь перечень из карты экранов.

## Как обсуждать сценарии

1. На главной или в каталоге откройте встречу. Поиск и фильтры меняют URL.
2. Нажмите «Присоединиться» или «Подать заявку», выберите профиль Алексея,
   затем подтвердите действие на странице. Свободная запись и ожидание выглядят по-разному.
3. У мероприятия можно переключить состояние в верхней панели: ожидание,
   подтверждение, отказ, снятая публикация, ошибка загрузки и загрузка.
4. В обсуждении можно написать текст. До входа он остаётся в поле при выборе
   демопрофиля; отправка требует отдельного подтверждения.
5. Для просмотра работы автора выйдите через профиль и войдите как Анна.
   Откройте сообщество «Темп», затем теннисную встречу и «Участники и заявки».
6. В создании заполните название, описание, направление, будущую дату/время и
   место; выберите способ записи, проверьте сводку и добавьте встречу в макет.
   Своё направление появляется без изменения исходника.
7. «Сбросить» в верхней панели возвращает весь макет к исходным вымышленным данным.

Изменения живут только в памяти вкладки. Перезагрузка сбрасывает демовход,
участие, сообщения и созданные встречи. Панель выбора состояния — инструмент
просмотра дизайна: например, UNPUBLISHED показывает вариант карточки и не
выполняет модерацию/удаление события во всём демонаборе.

## Оформление и адаптивность

Палитра и базовые параметры импортируются из брендбука 1.2. Знак в интерфейсе
повторяет геометрию двух наклонных линий. Спортивные иллюстрации и иконки созданы
в SVG; внешних фотографий и сетевых библиотек нет.

Используются Open Sans Regular/Bold и Montserrat Bold. Файлы шрифтов скопированы
из установленной системной поставки без модификации; лицензии находятся рядом:
[Montserrat OFL](assets/fonts/Montserrat-OFL.txt),
[Open Sans](assets/fonts/OpenSans-LICENSE.txt). Они относятся только к копиям
шрифтов прототипа; материалы брендбука и его ZIP не изменялись.

Предусмотрены настольная/планшетная сетка, мобильные карточки, раскрываемые
фильтры, нижняя навигация, уменьшение движения и клавиатурный фокус. На телефоне
декоративная иллюстрация hero скрывается, чтобы приблизить поиск к первому экрану.

## Проверка и ограничения

- Проверка синтаксиса обоих JS-файлов и наличие локальных ресурсов проверены.
- Изолированная проверка JS с имитацией DOM прошла: шесть маршрутов, фильтрация,
  пустая выдача, вход, запись/заявка/решение, состояния, вопрос после входа,
  создание со своим направлением, предупреждение об уходе и сброс.
- Это не браузерный E2E-тест. Встроенный браузер не ответил при подключении
  к странице и снимку; визуальная проверка ширин 320/390/768/1280 остаётся открытой.
- Страницы полного административного контура, кабинета допуска организации,
  восстановление публикаций, редактирование профиля и настоящая авторизация
  не реализованы в этой версии макета.
- Встречи примера имеют фиксированные даты октября 2026 года. Для показа позже
  даты можно обновить в data.js; создание своей встречи проверяет будущее время.

Соответствие обязательным требованиям оценивается позже на работающем продукте.
Макет не закрывает техническую приёмку S1–S6/A1–A6.
