# Рядом — дизайн-прототип 0.3

Локальный интерактивный макет для обсуждения внешнего вида и переходов.
Все люди, организации, места встреч и события — вымышленные примеры.
Это не реализация бизнес-логики из постановки: API, БД и серверной авторизации нет.
Стек Go/React и настоящий вход утверждены для приложения; этот отдельный HTML-макет сохраняет прежний демовыбор.

## Открыть

Откройте [index.html](index.html) в обычном браузере. Установка зависимостей не нужна.
Сохраните структуру каталогов: CSS использует [токены брендбука](../../brandbook/assets/tokens.css).
Шрифты находятся локально.

Для просмотра через HTTP из корня репозитория:

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Затем откройте [локальный прототип](http://127.0.0.1:4173/design/prototype/).
Остановка сервера — Ctrl+C. Это просмотр статических файлов, не запуск будущего
продукта. HTML и JS проверялись с HTTP 200; временный сервер проверки остановлен.

публичные профили, вход/регистрация, личный кабинет,
свои встречи, создание с выбором SVG-обложки, управление составом,

[Карта покрытия](coverage.md) перечисляет адреса, состояния, связные пути и ограничения.
Переключатель экранов открывает страницу, но не выдаёт человеку права: для
закрытого экрана нужно выбрать соответствующий демопрофиль.

| Демопрофиль | Что смотреть |
| --- | --- |
| Алексей Миронов | Поиск, запись/заявка, обсуждение, свои встречи и личное создание |
| Анна Лебедева | Автор исходных встреч, заявки участников, собственные организации |

## Как пройти новые пути

1. Войдите как Анна, откройте «Мои организации». Есть допущенный «Темп», ожидающие
   «Ход» и «Пульс», «Дворовые встречи» без заявки и «Высота» с отказом.
2. Создайте новый профиль организации или откройте «Дворовые встречи» и отправьте
   заявку. Профиль пока закрыт; публикация от организации недоступна.
3. Смените профиль на Марину. В модерации организаций найдите заявку и предоставьте
   допуск. На другой заявке проверьте отказ: без причины действие не выполняется.
4. Вернитесь к Анне и откройте тот же кабинет. Результат виден; после допуска
   есть публичная страница и «Создать встречу от организации» с предвыбранным автором.
5. Для модерации встречи Марина открывает «Встречи» в административном разделе.
   У каждого сообщения есть своё действие скрытия; в диалоге видны автор и фрагмент.
6. При снятии встречи укажите причину. Она исчезнет из публичных списков; Анна
   увидит причину, записавшийся Алексей — недоступность и прежний статус записи.
   Посторонний человек по прямой ссылке увидит «Страница не найдена».
7. «Сбросить» в верхней панели возвращает весь макет к исходным данным.

У администратора нет действий принятия/отказа по чужим заявкам участников.
Снятие блокирует также новые вопросы и решения автора; записи не отменяются
автоматически. Скрытый оригинал сообщения доступен в административном разделе,
обычное обсуждение показывает заглушку и сохраняет остальной разговор.

## Основные пользовательские пути

- Поиск и фильтры меняют URL. Новый поиск сохраняет направление, режим и дату.
  Пустой город означает все города; Красноярск на главной — выбор демо, не геолокация.
- «К результатам» возвращает последнюю выдачу с параметрами в памяти вкладки;
  позиция прокрутки пока не восстанавливается. Мобильные фильтры сохраняют раскрытие.
- Свободная запись подтверждается сразу; заявка ожидает автора. Для просмотра
  обоих вариантов подходят пробежка и теннис. У автора есть «Участники и заявки».
- Гость может набрать вопрос до входа. Текст сохраняется при выборе демопрофиля
  или регистрации, а отправка требует отдельного подтверждения.
- Создание встречи содержит три шага, своё направление, выбор автора и сводку.
  Встречи своей допущенной организации публикуются без нового согласования.
- Уход по внутренним ссылкам или перезагрузка предупреждает о заполнении любой
  значимой части формы встречи или организации. Кнопки истории браузера пока не
  вызывают такой диалог; заполнение остаётся в памяти до явного сброса/смены профиля.

На странице встречи панель дизайна дополнительно показывает ожидание,
подтверждение, отказ, недоступность, ошибку загрузки и загрузку. Эти переключения
показывают вариант оформления. Реальное для макета снятие выполняется из модерации
и меняет общий набор данных; переключатель состояния этого не заменяет.

## Оформление и адаптивность

Параметры импортируются из брендбука 1.2. Знак повторяет геометрию двух наклонных
линий. Спортивные иллюстрации и иконки созданы в SVG; внешних фотографий и библиотек нет.
Используются локальные Open Sans Regular/Bold и Montserrat Bold без модификации:
[Montserrat OFL](assets/fonts/Montserrat-OFL.txt), [Open Sans](assets/fonts/OpenSans-LICENSE.txt).
Материалы брендбука и его ZIP не изменялись.

Предусмотрены настольная/планшетная сетка, мобильные карточки административных
списков, вертикальные формы, нижняя навигация и уменьшение движения. В диалоге
модерации можно прокручивать длинную причину. Время подписано с UTC+7 для демо.

## Проверка и ограничения

Из корня репозитория при наличии Node.js:

```bash
node --check design/prototype/app.js
node --check design/prototype/data.js
node scripts/check_prototype.cjs
```

Проверены синтаксис, локальные ресурсы и последовательности с имитацией DOM:
основные маршруты, фильтры, вход/регистрация, запись и решения автора, создание,
подача/допуск/отказ организации, поиск администратора, модерация сообщения,
снятие встречи, доступы и предупреждение о заполнении формы.

Это не браузерный E2E-тест. Последующая попытка подключения заработала:
выполнен визуальный проход всех 18 экранов на 1280/390 px, ключевых страниц
на 320/768 px и нескольких связных локальных путей.
[Отчёт и снимки](../reviews/2026-10-19/README.md) описывают точный объём,
исправления и оставшиеся проверки доступности/устройств.
Состояния сетевого сбоя/отправки/неизвестного результата всех операций,
истечение сессии и пагинация пока не показаны во всех контурах.

Все изменения живут в памяти **одной вкладки**. Перезагрузка сбрасывает вход,
организации и решения, участие, сообщения и встречи. Нет настоящей авторизации,
независимых сессий, API или хранения. Фиксированные события — октябрь 2026 года;
для более поздней демонстрации даты нужно обновить. Правило действий в уже
начавшейся встрече ещё не согласовано; главная выбирает только будущие встречи.

Соответствие обязательным требованиям оценивается позже на работающем продукте.
Макет не закрывает техническую приёмку S1–S6/A1–A6.

## Проверка обновления 0.3

Из корня, при запущенном сервере на 4173 и установленных зависимостях приложения:

```bash
node --check design/prototype/app.js
node --check design/prototype/data.js
node scripts/check_prototype.cjs
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/google-chrome node scripts/check_prototype_browser.cjs
```

Первая проверка имитирует DOM. Последняя запускает настоящий браузер,
проверяет обложки/выбор/сброс при смене спорта, read-only каталог организаций,
320/390/768/1280 px и сохраняет снимки в `.artifacts/prototype-update/`.
Это не проверка продуктового API, сессий или хранения в БД.
