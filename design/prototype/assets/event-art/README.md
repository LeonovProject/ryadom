# Иллюстрации встреч

22 самостоятельных SVG для локального дизайн-макета 0.3. Основа — 21 файл
из коммита **9120106785183ddb6693e98eea2ff3f8725a0fe1** (`origin/kirill`),
плюс отдельная `volleyball.svg`, чтобы волейбол не показывался с теннисной ракеткой.
[Разбор интеграции](../../../reviews/2026-10-20/README.md) описывает отбор изменений.

| Направление | Иллюстрации |
| --- | --- |
| Бег | stride, stride-blue, stride-alt |
| Теннис | court, court-blue, court-alt |
| Шахматы | chess, chess-red, chess-alt |
| Волейбол | volleyball |
| Зарядка/йога | yoga, yoga-red, yoga-alt |
| Другие примеры | hike, hike-alt, hike-warm; bike, bike-blue, bike-alt; swim, swim-alt, swim-red |

Все файлы имеют viewBox 400×150 и проходят **тот же MEDIA-00 / профиль 1.0.0**,
что пользовательская загрузка: максимум 128 КиБ, без style/text/use/clipPath,
внешних ссылок и редакторских пространств имён. Проверены исходный и
нормализованный размер. Размер подготовленных файлов — примерно 0.7–12 КиБ.

При подготовке редакторские атрибуты удалены, видимые CSS-свойства перенесены
в разрешённые SVG-атрибуты, локальный use развёрнут, надписи преобразованы в
контуры из шрифтов брендбука. Струны ракетки court-blue пересечены с эллипсом
аналитически вместо clipPath. Рисунки не требуют шрифтов/JS или сети при показе.
Цвет в иллюстрации не обозначает состояние участия/модерации.

## Воспроизведение подготовки

[prepare_prototype_art.py](../../../../scripts/prepare_prototype_art.py) — узкий
инструмент для **этих проверенных редакторских исходников**, а не замена
серверного валидатора произвольной загрузки. При незнакомой геометрии/стиле
он останавливается. FontTools нужен только при пересборке иллюстраций;
в приложение новая Python-зависимость не добавлена.

Пример из корня, после получения указанного коммита, с отдельным каталогом:

```bash
mkdir -p /tmp/ryadom-art-source
git archive 9120106785183ddb6693e98eea2ff3f8725a0fe1 design/prototype/assets/event-art | tar -x -C /tmp/ryadom-art-source
python3 -m venv /tmp/ryadom-art-tools
/tmp/ryadom-art-tools/bin/pip install fonttools==4.67.0
/tmp/ryadom-art-tools/bin/python scripts/prepare_prototype_art.py --source-dir /tmp/ryadom-art-source/design/prototype/assets/event-art --output-dir design/prototype/assets/event-art
go -C apps/api run ./internal/platform/svg/cmd/checksvg "$PWD"/design/prototype/assets/event-art/*.svg
```

Нужен закреплённый Go 1.27.2. `volleyball.svg` подготовлена отдельно обычными
векторными примитивами, скрипт её не перезаписывает. После изменения геометрии
просмотреть весь набор в браузере и повторить проверку общего SVG-пакета.

## Граница продукта

Выбор обложки в HTML-макете — иллюстрация дизайна в памяти вкладки. Он не
вводит production-каталог фонов, coverPresetId или новое поле createEvent.
В приложении сохраняется выбранная пользователем загрузка SVG и существующие
операции MEDIA-01B/C, проверка сервера и 128 КиБ. Эти файлы пригодны как
подготовленные примеры для такой загрузки; реальная доставка/сохранение
проверяются отдельно. OpenAPI 0.13.0 и брендбук 1.2 не изменены.
