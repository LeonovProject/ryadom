# API Рядом: текущий контракт

Раннее предложение заменено **интеграционным контрактом 0.13.0** по поручению
пользователя от 19 октября 2026 года. Этот путь сохранён для существующих ссылок.

- [OpenAPI 3.0.3](../../packages/contracts/openapi.yaml) — 60 операций, точные DTO,
  обязательные/nullable-поля, параметры, HTTP-статусы и operationId.
- [Правила API](api-v1.md) — права, состояния, повторы, ошибки, курсоры и связь с экранами.
- [Пакет контракта](../../packages/contracts/README.md) — HTTP-примеры, отрицательные
  примеры, проверка и конфигурация генерации Go/TypeScript.
- [Результаты проверки](validation.md) — валидация схем и примеров, генерация и компиляция.

Для параллельной реализации используется одна версия OpenAPI. Приложений,
работающего API, миграций и контейнерной среды пока нет. Подготовка контракта
не запускает реализацию, агентов, публикацию или Git-операции.
