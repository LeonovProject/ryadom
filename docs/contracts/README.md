# Общие контракты

Этот каталог предназначен для согласованных моделей и операций, которые используют
несколько исполнителей. Реализованного API сейчас нет.

## До разделения веба и сервера

Зафиксируйте для каждой операции:

- роль и права доступа;
- входные данные, результат и обязательные поля;
- состояния до и после действия;
- ошибки, повторный запрос и неопределённый результат;
- последствия для каталога, организатора и участника;
- владельца контракта и зависимые модули.

Минимальные области согласования: пользователь, организация и её членство,
встреча, способ присоединения, участие и заявка. Механика вопросов определяется
после продуктового решения. Имена полей и серверные перечисления ещё не заданы.

## Независимые состояния

Не объединяйте допуск организации, публикацию встречи и участие человека в одно
поле. Не приравнивайте снятие с публикации к отмене или удалению. Подписи из
[states.json](../../brandbook/assets/states.json) — материал дизайна, а не готовая
схема переходов API.

Предпочтительный следующий артефакт — документ операции со ссылкой на решение
в `docs/product/`. Машиночитаемая схема и общие типы добавляются после выбора
стека и формата контракта. Не поддерживайте разные независимые копии одного API
в вебе, сервере и мобильном приложении.
