# Профиль SVG 1.0.0 для реализации MEDIA-00

Техническое решение подготовки 20 октября 2026 года. Одинаковое для готовых
аватаров, личных загрузок и фонов. Машинный источник —
[svg-policy.json](../../packages/contracts/svg-policy.json); набор ожидаемых
результатов — [svg-cases.json](../../packages/contracts/examples/svg-cases.json).
Профиль зафиксирован, серверный валидатор ещё предстоит реализовать в MEDIA-00.

## Разбор и пределы

Используется стандартный `encoding/xml` закреплённого Go 1.27.2, потоковый
`Decoder.Token`, `Strict=true`, без пользовательской Entity и CharsetReader.
До разбора проверяются UTF-8 и исходные 131072 байта. DOCTYPE и любые Directive
отклоняются; внешние сущности не разрешаются. XML-декларация допустима только
в начале, encoding только UTF-8, version только 1.0. Другие ProcInst запрещены.
Комментарии можно отбросить. Текстовые узлы разрешены только из пробельных
символов; после корня допустим только пробел. Ровно один корень svg.

Корень и все элементы относятся к `http://www.w3.org/2000/svg`; иные пространства
имён, xlink, повторяющиеся атрибуты и вложенный svg запрещены. Обычный xmlns
допустим только на корне, без дополнительных деклараций. При сериализации
нужен один default namespace, без добавления повторного xmlns к каждому узлу.

| Предел | Включительное значение |
| --- | --- |
| Исходный / нормализованный SVG | 131072 байта UTF-8 каждый |
| Глубина, корень = 1 | 16 |
| Все элементы, включая корень/defs/stop | 512 |
| Атрибуты на элемент, включая xmlns | 32 |
| Одно декодированное значение атрибута | 32768 байт UTF-8 |
| Сегменты всех path, включая неявные повторы | 4096 |
| Числовые значения во всех атрибутах вместе | 16384 |
| Пары points у одного polyline/polygon | 2048 |
| Преобразования в одном transform | 8 |
| Градиенты / stop во всём документе | 32 / 256 |
| Длина ID | 64 ASCII-символа |
| Ширина/высота viewBox и viewport | больше 0, до 4096 |
| Модуль любого числа | 1000000, только конечные значения |

Лимиты суммируются до построения нормализованного дерева. Никакого
«обрезать до допустимого»: превышение отклоняет весь файл. Числа в экспоненциальной
записи допустимы после проверки конечности и диапазона; NaN/Inf запрещены.
Ширина/высота корня положительны. Геометрические width/height/r/rx/ry
неотрицательны, pathLength строго положителен. Пустые width/height
атрибуты не принимаются. На корне width/height необязательны, только число/px;
viewBox обязателен и содержит ровно четыре числа, положительные третье и четвёртое.

## Разрешённая графика

Элементы и точные атрибуты перечислены в JSON. Графические svg/g/path/rect/circle/
ellipse/line/polyline/polygon допускают общие presentationAttributes. defs содержит
только linearGradient/radialGradient; градиент — только stop; stop — пустой.
defs допускается непосредственно в корне один раз, остальные контейнеры — svg/g.
Градиенты не наследуются через href и не вкладываются друг в друга.

- Цвета: `#RGB`, `#RGBA`, `#RRGGBB`, `#RRGGBBAA`, none/black/white/transparent.
  Регистр hex не важен, нормализация делает его единым. rgb()/hsl()/currentColor
  и произвольные имена не поддерживаются; пользовательские цвета не ограничены
  палитрой бренда.
- В fill/stroke допустим строго `url(#id)` существующего градиента без fallback.
  ID уникален, `[A-Za-z][A-Za-z0-9_-]{0,63}`; только градиенты имеют ID.
  forward reference допустим после общей проверки ссылок. Других URL нет.
- opacity/fill-opacity/stroke-opacity/stop-opacity: 0..1; offset: 0..1 или 0..100%.
  Координаты градиента допускают числа или проценты 0..100%; gradientUnits —
  objectBoundingBox/userSpaceOnUse, spreadMethod — pad/reflect/repeat.
- fill-rule — nonzero/evenodd; stroke-linecap — butt/round/square;
  stroke-linejoin — miter/round/bevel; stroke-miterlimit — 1..10.
  stroke-width неотрицателен; dasharray — none либо до 32 неотрицательных чисел,
  не все нулевые. Проценты и единицы у геометрии, кроме оговорённых случаев, запрещены.
- preserveAspectRatio — none либо xMin/xMid/xMax с YMin/YMid/YMax и необязательным
  meet/slice. Пробелы нормализуются, неизвестное значение отклоняется.
- transform/gradientTransform: matrix(6), translate(1–2), scale(1–2), rotate(1/3),
  skewX(1), skewY(1). Скобки/арность/разделители разбираются полностью.
  Модуль scale и первых четырёх коэффициентов matrix до 100; модуль skew < 85°.
- path: только M/L/H/V/C/S/Q/T/A/Z в обоих регистрах; первая команда M/m.
  Нужен разбор грамматики и арности, включая неявные повторения, дополнительную
  пару M как L и флаги дуги строго 0/1; у дуги радиусы неотрицательны.
  Подсчёт одних букв недостаточен. Пропуски/лишние аргументы отклоняются.

Неизвестные элементы/атрибуты отклоняются: script, foreignObject, image, use,
text, style, class, обработчики on*, href, фильтры, маски, анимации и CSS не входят
в профиль. Это явное ограничение совместимости MVP, а не очистка любого SVG.

## Результат, ошибки и проверка

Один серверный пакет проверяет и повторно сериализует разрешённые элементы и
атрибуты в стабильном порядке, без комментариев/XML-декларации и внешних ресурсов.
После нормализации снова проверяется предел байтов; повторная нормализация
байт-в-байт одинакова. Бюджет чисел считает каждый скаляр геометрии, viewBox,
преобразований и presentation-атрибутов, включая флаги дуг; цифры hex-цветов
и идентификаторов не считаются числами. Готовые аватары проходят тот же пакет до включения в образ.
Изменение содержимого нормализацией не должно менять вид исходного рисунка.

Размер даёт 413 PAYLOAD_TOO_LARGE; XML/неподдерживаемая графика/сложность —
422 VALIDATION_ERROR с fieldErrors `/svg` и понятным сообщением. Предыдущее
изображение/статус/версия сохраняются. Существующий JSON-предел 1 МиБ не меняется.

MEDIA-00 запускает весь набор случаев, границы каждого лимита, повторную
сериализацию, сравнение вида допустимых образцов и Go fuzzing с ограниченным
временем. Валидация JSON-формы контракта не заменяет эти проверки. В тестах
размеры добираются валидным SVG-комментарием, а не лишними графическими узлами;
точное число байтов проверяется после UTF-8-кодирования.

Основание: [encoding/xml](https://pkg.go.dev/encoding/xml),
[грамматика path SVG](https://www.w3.org/TR/SVG2/paths.html),
[типы SVG](https://www.w3.org/TR/SVG2/types.html).
Численные пределы — выбранные ограничения проекта, не требования этих источников.
