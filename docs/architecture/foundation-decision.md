# ADR-002 — Общая основа перед передачей разработчикам

Дата: 20 октября 2026 года. Статус: принято в рамках поручения пользователя
выполнить подготовку перед передачей бэкенду и фронтенду. Бизнес-функции не
входят в эту подготовку; объём DEC-17 не сокращается.

## Зафиксировано

- Go **1.27.2**, PostgreSQL **17.11**, pgx **5.11.0**; chi/runtime/kin-openapi
  сохраняют проверенные версии контракта. Полный результат разрешения — go.mod/go.sum.
- Node **22.23.1** в образе и .node-version; локальный pnpm также использует
  доступный Node **24.19.0**. Обе ветки допустимы engines; pnpm **11.25.0**.
- React/React DOM **19.3.1**, Vite **8.3.4**, plugin-react **6.1.2**,
  TypeScript **5.9.3**, React Router **7.18.4**, TanStack Query **5.104.5**,
  Radix Dialog **1.3.1**, CSS Modules. Выбор и точные версии закреплены в package.json
  и pnpm-lock.yaml. SPA, без SSR. Другие примитивы добавляются через координатора.
- openapi-fetch **0.17.0**, openapi-typescript **7.6.1**, oapi-codegen **2.4.1**.
  Общий клиент packages/api-client и apps/api/internal/transport/openapi/api.gen.go
  генерируются одной командой. Исходный OpenAPI 0.13.0 не менялся.
- Vitest **5.0.5**, Playwright **1.64.1** закреплены для будущих проверок,
  Swagger UI Dist **5.34.0** — для DOCS-01. Это не означает, что сценарии,
  браузеры Playwright или сетевой Swagger уже реализованы/проверены.
- sqlc **1.31.1** и goose **3.29.0** закреплены для DB-01/OPS-01. Их интеграция
  и реальные SQL-запросы/миграции выполняются в соответствующих карточках.
- Образы Go, Node и PostgreSQL закреплены тегом и проверенным digest в
  [versions.json](../../tools/foundation/versions.json). Установленные пакеты
  не обновляются независимыми исполнителями без изменения общей основы.

pnpm сохраняет точные версии и проверяет peers; install-скрипт @scarf/scarf
явно отключён как необязательный для локального Swagger. Прочие необходимые
скрипты перечислены в allowBuilds. Разрешение установки и build-политики входят
в общую проверку с frozen lockfile. Нет автоматического обновления библиотек.

## Структура и границы

apps/api — отдельный Go-модуль; apps/web и packages/api-client — pnpm workspace.
Транспортные DTO не дублируются в предметных модулях. Временная веб-страница
проверяет сборку; FE-01 заменяет её оболочкой. Проверка БД в internal/foundation
делает SELECT 1 без создания схемы и не является health/ready продукта.

compose.foundation.yaml — только изолированная проверка зависимостей с временной
PostgreSQL, без открытых портов и существующих БД. Продуктовая Compose-среда,
постоянный том, секреты, миграции, seed, proxy и Swagger — OPS-01/DOCS-01.
Первый общий HTTP-путь проверяется после BE-01/FE-01/DB-01; BASE-01 не подменяет его.

Владельцы и первые поручения закреплены в [пакете передачи](../development/handoff/README.md).
Текущий координатор отвечает за зависимости, генерацию и контейнеры; DATABASE
один ведёт SQL; BACKEND/FRONTEND не меняют эти файлы попутно. Имена ролей не
означают автоматического запуска агентов или права отправлять им сообщения.

Для штатного сида выбран Красноярск, разные дисциплины: бег, футбол, шахматы,
зарядка. Первая демоперсона — alex, представитель организации — anna,
администратор — marina по DEC-20. Это подготовленные данные, не ограничение города.
Расписание остаётся относительным к демонстрации, все основные доступы ACTIVE.

SVG-профиль **1.0.0** закрепляет encoding/xml и лимиты: 128 КиБ, глубина 16,
512 элементов и остальные конечные бюджеты. [Точные правила](svg-profile.md)
и conformance-случаи передаются MEDIA-00; собственный второй валидатор не создаётся.
