# Доступы для самостоятельной проверки

Принято пользователем 20 октября 2026: **`/demo`**, файл **`/demo/accounts.txt`**
и выбор аккаунта в форме входа. DEC-24 дополняет
[настоящий вход DEC-20](../architecture/authentication.md), без новых API/ролей/таблиц.

## Поведение

- Ссылка «Демоаккаунты» находится в подвале и форме входа. Прямые ссылки открываются без сессии.
- Страница показывает имена, назначение, email и пароли шести вымышленных аккаунтов DB-02.
  «Подставить данные» открывает форму и заполняет email/пароль. В самой форме есть сворачиваемый список.
- Выбор не выполняет вход. Нужна явная кнопка «Войти» и обычный `POST /api/v1/auth/login`.
  Сервер проверяет пароль, блокировку, лимиты и создаёт JWT-cookie. До ответа нет подтверждения успеха.
- Данные можно отредактировать. Выбор отключён при запросе, ожидании лимита и неопределённом результате.
  Ошибки и безопасный returnTo сохраняются; пароли не передаются в URL или хранилища браузера.
- Если человек уже вошёл, форма предлагает сначала выйти. Выбор не заменяет действующую сессию.
  Между страницами передаётся только известный ключ из списка, не пароль.
- Файл UTF-8 `.txt` содержит те же данные и короткие описания. Состояния относятся к исходному сиду:
  действия экспертов меняют БД. Страница не создаёт и не сбрасывает данные.
- Анна — USER с организациями; отдельного входа организации нет. Борис в начальном наборе заблокирован:
  вход должен завершаться отказом. Назначение аккаунта не означает готовность всех модулей.

## Включение и источники

По умолчанию функция выключена. Для демопоставки задать **`WEB_DEMO_ACCESS=true`**
и **пересобрать web**. Веб получает публичный параметр сборки `VITE_DEMO_ACCESS=true`.
Это настройка показа доступов, не серверный `DEMO_MODE` административного сброса.
При выключении маршрут/ссылки/список отсутствуют, файл возвращает 404;
в собранных ресурсах нет демонстрационных email/паролей. Данные уже публичны в
исходниках сида: параметр не делает их секретными и не запрещает обычный вход.

[demo-accounts.json](../../apps/web/demo-accounts.json) — единый список для страницы,
выбора и файла. При изменении DB-02 обновить его вместе с
[инструкцией сида](../../apps/api/db/seed/README.md). Проверка сверяет его с фактическими данными Go.
API 0.13.0, БД и брендбук не меняются.

Для локального веба: `VITE_DEMO_ACCESS=true pnpm --filter @ryadom/web dev`.
Vite показывает интерфейс; для настоящего входа нужен общий контейнерный адрес.
После развёртывания пользователь передаёт экспертам `<адрес>/demo` и файл.

## Проверка

Скачивание по прямому URL/ссылке, все шесть доступов, отсутствие POST до явного
входа, сохранение returnTo, запрет молчаливой смены сессии, отказ Борису и обычные
лимиты; клавиатура и 320/390/768/1280 px; сборка с выключенной функцией.
Это не разрешение на сброс общей БД или внешнее развёртывание.
