актуальные файлы, а не сохранённая копия кода образа. Пересборка всех runtime-

Генератор oapi-codegen изолирован в tools/oapi-codegen с go.mod/go.sum и Go tool
directive. После наполнения кеша повторная генерация проверяется с GOPROXY=off;
не требуется динамический поиск latest/deprecation, свойственный go run package@version.
Зависимости предметного API не используются как независимый каталог инструментов.

В контейнерном прогоне выявлено и исправлено сканирование текстового
server_version_num в int: проверочный запрос явно приводит значение к integer.
Повторный прогон Go с PostgreSQL успешен. Это исправление теста подготовки,
не изменение модели БД или бизнес-контракта.
