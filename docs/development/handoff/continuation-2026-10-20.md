## Как получить общую базу

В каждой существующей рабочей копии сначала проверить `git status --short --branch`
и сохранить свою незавершённую работу. Затем получить origin и **точный SHA из
передачи**, а не произвольную вершину другой ветки:

```bash
git fetch origin
git merge --ff-only <SHA_ОБЩЕГО_КОММИТА>
```

Команда подходит, если собственная ветка ещё является предком общей базы.
При новых локальных коммитах нужен обычный merge с разбором конфликтов;
при незакоммиченных файлах сначала сохранить их. Не применять reset/force push,
не заменять файлы целиком версией другой стороны. Существующие worktree и ветки
этой подготовкой не перемещаются. Новые задачи получают отдельную ветку
`codex/<task-id>-<short-name>` и worktree от указанного SHA.

  назначениями. QR-01 и shared/qr/** закреплены за COORDINATOR.

  Compose-проверку соответствующего пути. В следующем назначении указывается
  обновлённый общий SHA. Контрактные фикстуры не заменяют реальные операции.
