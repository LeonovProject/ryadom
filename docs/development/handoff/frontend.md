## Основа

React/TypeScript/Vite, React Router, TanStack Query, CSS Modules и Radix Dialog
закреплены в package.json и pnpm-lock.yaml. Только SPA, без серверного React.
Типы и клиент — packages/api-client, источник — OpenAPI 0.13.0. Запросы same-origin
с cookie; JWT не хранится в JS. Не создавать собственные копии DTO/статусов.
Токены — brandbook/assets/tokens.json и производный CSS. Шрифты брендбука
подключаются локально в FE-01, не заменяются внешним CDN.

FE-01 начинает с общей оболочки, навигации, маршрутов и доступных компонентов;
бизнес-поведение — по следующим карточкам. Корневые зависимости/генерация,
Docker и подключение общих блоков изменяются через COORDINATOR.
