20 октября 2026, Asia/Krasnoyarsk. Поверх общей базы a976427 объединены:

- BACKEND: **8680600b8cae9e08dd659e0f6f8688116231ea96**, BE-07 c81b00b,
  BE-08 1a00a81, BE-09 8680600.
- FRONTEND: **e423568db16b46a881b26f34c67a754cc78c856f**, FE-08 d4f1e1b,
  FE-09 e7d4d30, FE-10 8dde74e; проверенный продуктовый SHA —
  **8dde74e23345b60c314519d8676b453a206bfcfb**, далее только отчёт передачи.

Слияние без конфликтов. Продуктовый код координатор не менял. Рабочие копии
исполнителей сохранены; на момент выбора SHA обе чистые. Новый коммит Кирилла
не рассматривался. API **0.13.0**, общие DTO, SQL-схема/миграции, зависимости,
бренд и Compose не менялись. Новые SQL-запросы/sqlc входят в серверный пакет.

## Принятые проверки исполнителей

- [BE-07](../../../../../apps/api/internal/modules/participation/README.md):
  адресные PostgreSQL/race, запись/решения/конкуренция, начало/часовые зоны,
  курсоры и реальный HTTPS с сохранностью данных/сессий.
- [BE-08](../../../../../apps/api/internal/modules/discussion/README.md):
  PostgreSQL/race обсуждения/скрытия, версии/жалобы/пагинация/конкуренция,
  HTTPS и сохранность.
- [BE-09](../../../../../apps/api/internal/modules/moderation/events/README.md):
  поиск/приватность/атомарное снятие, гонка с записью, HTTPS и сохранность.
- [FE-P2](../../../../../apps/web/src/features/participation/FE-P2.md):
  12 адресных браузерных, 3 модульных, повтор затронутого гостевого входа,
  типы/сборка/образ. Реальный старый API проверял только честные ошибки
  отсутствующих BE-07/08; совместные S3–S5 оставались открыты.

SHA-256 каждого серверного отчёта сверены с его карточным коммитом; объединение
последних версий даёт **29 файлов**, совпадающих с текущей копией.
[Зафиксированные хеши](verified-sources.json) учитывают последующие изменения
main.go в BE-08/09. Фронтенд от проверенного продуктового SHA отличается только
отчётом. Полные прежние Go/race и браузерные наборы не повторялись: изменения
без конфликтов, подтверждённые предметные проверки приняты по пакетному процессу.
Общая QA-01 и итоговая DELIVERY остаются отдельными незакрытыми карточками.

## Совместный проход

Добавлен [воспроизводимый проход](../../../../../infra/tests/p2/accept.py)
с [браузерной частью](../../../../../infra/tests/p2/browser.cjs).
Новый случайный Docker Compose-проект, свой том/секреты/TLS/loopback-порт;
seed выполняется только в этой новой базе. Запросы и формы настоящие, без моков.

Общие API/web собраны из объединённых исходников. Docker проверил sqlc,
TypeScript и production build. Неизменённые migrate/seed взяты из принятого
BE-09. Проверенные образы:

- API `ryadom-p2-api`: `sha256:5eb3723d6b9ebb35cb70912e8d1148377861c1c933e32552ed4bcf7294220ae9`.
- web `ryadom-p2-web`: `sha256:17a49c571d395cfdeaead3a865fe6de69c997ae3bef89e29d3617c1d317d5662`.

Пройдено:

1. S3: OPEN → CONFIRMED через кнопку; встреча видна в трёх ближайших на главной.
2. S4: две APPROVAL-заявки, принятие и отказ в составе автора; актуальные
   состояния у двух участников, отклонённая заявка не подаётся повторно.
3. S5: незаписанный человек задаёт вопрос, автор отвечает, другая сессия читает
   ответ после обновления. Ровно три POST записи, два решения и два сообщения
   через UI; автоматических повторов и ошибок JavaScript нет.
4. A3/S6 на API с проверкой результата в пользовательском UI: ADMIN скрывает
   одно сообщение по revision; публичный оригинал исчезает. ADMIN снимает
   встречу с причиной: состав/статусы сохранены, новая запись/обсуждение закрыты,
   в полном личном списке остаётся ограниченная карточка без времени/адреса.
   ADMIN без авторства не читает состав. Административные формы FE-11 ещё впереди.
5. Обычный down/up того же тестового проекта/тома сохраняет решения, скрытие
   и снятие; новый браузерный проход читает их из штатных UI/API.
6. Независимые аккаунты, зона устройства Pacific/Honolulu, ширины
   320/390/768/1280; проверено отсутствие горизонтального переполнения.
   Просмотрены снимки личной главной, состава и обсуждения.

Первый запуск остановился на неверном ожидании теста: новая встреча через три
дня закономерно не входила в три ближайших при существующих записях сида.
Тест создал более близкую встречу; полный адресный проход и пересоздание прошли.
Продукт для этого не менялся. Проверка точной границы начала/полночи, длинной
пагинации и конфликтов принята из адресных серверных/клиентских свидетельств;
данный совместный проход не объявляет полный UI-регресс этих краёв.

Воспроизведение после сборки образов с префиксом ryadom-p2:

```bash
python3 infra/tests/p2/accept.py --source "$PWD" --screenshots /tmp/ryadom-p2-browser
```

Результат: PASS P2 UI, PASS P2 persistence, PASS P2 combined HTTPS.
Временный проект, его сети и том удалены. Проверки репозитория/manifest,
контракта (60 операций/100 схем/280 примеров/64 отрицательных), синтаксиса
нового прохода и diff --check пройдены. OpenAPI/генерация DTO не менялись;
повтор генерации Go/TS не требовался.

## Просмотр и продолжение

Общий просмотр: http://127.0.0.1:4180/; демодоступы `/demo`, Swagger `/api/docs/`.
API/web обновлены проверенными образами, БД/том/ключ JWT сохранены.
Общий preview отдельно прошёл чтение публичных маршрутов/демофайла/Swagger,
настоящий вход, личную главную и предстоящие встречи в API/UI, без бизнес-записей. Удалённый
временный env восстановлен приватно из действующих контейнеров без вывода
секретов. Seed/reset и тестовые бизнес-операции в общей БД не выполнялись.

Приняты BE-07/08/09 и FE-08/09/10. Следующие подготовленные пакеты:
**BE-P3: BE-10 → BE-11 → BE-12** (направления, жалобы/восстановление, демосброс);
**FE-P3: FE-11 → FE-12 → FE-13** (модерация, направления, жалобы).
FE-11 уже может проверяться на текущем API; реальные FE-12/13 потребуют
BE-10/11 из параллельного пакета. Наличие фикстур не закрывает эту зависимость.

Оба исполнителя берут точный SHA итогового коммита этой интеграции через обычное
слияние/fast-forward подходящей чистой ветки, без reset. Эта передача не запускает
агентов. Блокировка аккаунтов, UI демосброса, личные SVG/фоны, помощник,
печатное приглашение, QA/DELIVERY сохраняются в очереди. 27 карточек завершены,
21 остаётся; это промежуточный результат.
