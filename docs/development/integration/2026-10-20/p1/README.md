# Объединение BE-P1 и FE-P1

20 октября 2026, Asia/Krasnoyarsk. По поручению пользователя объединены
завершённые коммиты агентов поверх e7d6958, без переписывания их истории:

- BE-P1: **b6896516b916c0f80cadf3bcf94d92279c8fb3b1**, карточки BE-04/05/06
  (c74dfcd, 7754d7d, b689651).
- FE-P1: **fccce114e0b04f7a7e6703ecc3d65ec17d08b66c**, проверенный продуктовый
  код **9ba3c19**; сохранены прежние 8332364/890200c и промежуточный merge.

Незакоммиченная работа бэкенда над участием осталась в его worktree и сюда не
переносилась. Фронтенд-worktree не изменялся. Новый коммит Кирилла не затрагивался.

## Принятые свидетельства

- [Серверный отчёт BE-P1](../../../../../apps/api/internal/modules/organizations/README.md):
  полный PostgreSQL/race, S1/S2 по HTTPS/формам, три роли, обе ветки допуска,
  отказы/повторы/конкуренция/сохранение. Хеши всех 30 производственных файлов
  из code-sources.json совпали с объединёнными исходниками.
- [Фронтенд FE-P1](../../../../../apps/web/src/features/events/create/FE-P1.md):
  111/111 модульных и 196/196 браузерных проверок, без retries; реальная BE-03
  для каталога/карточки и подготовка формы. От проверенного 9ba3c19 отличается
  только отчёт передачи, производственный код не менялся.

Эти полные наборы повторно не запускались. Общая проверка закрывает оставшуюся
между пакетами зависимость: FE-P1 ранее не выполняла публикацию, а BE-P1
проверяла существующий веб e7d6958, без новых правок фронтенда.

## Что объединено

- createEvent: личная/организационная публикация и атомарное разрешение своего
  направления; правила времени, допуска и неопределённого сетевого ответа.
- Создание организации, личные кабинеты, подача, публичная APPROVED-страница;
  административный поиск/карточка/допуск/отказ с причиной.
- Продолжение каталога: фильтры/перечитывание, возврат к положению и фокусу.
- Карточка → профиль автора → карточка → исходный каталог, безопасные ссылки.
- Сводка создания → исправление нужного раздела → проверка → отдельная публикация.

Конфликтов слияния не было. Дополнительных продуктовых правок координатор не
вносил. API 0.13.0, SQL-схема, Go/TS DTO, зависимости, бренд и контейнерная
конфигурация прежние; изменились предметные SQL-запросы/sqlc из BE-P1.

## Проверка объединения

Совместный прогон **пройден**. Использован существующий скрипт BE-P1
http_accept.py с --browser и image-prefix ryadom-p1:
API и web собраны из общей рабочей копии, неизменённые migrate/seed взяты из
проверенной серверной сборки. Это отдельный случайный Compose-проект со своими
секретами/TLS/портом/томом. Общая БД preview не используется и не сбрасывается.
Сборка API сверила sqlc; web прошёл typecheck/production build. Контрольный ID web
fc831426a6ca680cfd1d6613817c7868d99a21f623e75457d8c795bcad25feef совпал с
проверенным образом FE-P1.

Подтверждены реальные S1/S2: личная встреча с новым спортом → каталог → второй
читатель; профиль организации → заявка → допуск ADMIN → публикация от организации
→ публичная страница/встреча у второго читателя. Отказ с причиной, повторные
решения/конфликты, приватные права и сохранение данных/сессий после down/up прошли.
В браузере — три независимых контекста, ровно ожидаемые POST, без повторных
публикаций и JS-ошибок; просмотрены desktop и мобильная карточка. Тестовый проект,
сети и его том удалены. Полные Go/race и 196 Playwright повторно не запускались.

По этим свидетельствам приняты BE-04/05/06 и FE-03/04/05. Существующие FE-06/07
не менялись в параллельном FE-P1, но также получили реальный общий S2-проход
кабинетов/административного допуска с BE-05/06 — их интеграционная зависимость
закрыта. Это не приёмка участия/обсуждения или оставшихся административных путей.

Общий preview 4180 обновлён проверенными API/web; его PostgreSQL/том/ключи
сохранены. В общей БД seed/reset/создание тестовых встреч не выполнялись.
Проверки репозитория/manifest и git diff --check пройдены.

## Продолжение

Оба исполнителя получают SHA итогового коммита этого объединения. Из чистой
ветки, являющейся его предком, допустим merge --ff-only; при собственной новой
работе сначала сохранить её и выполнить обычное согласованное слияние, без
reset/force push. Текущая незакоммиченная BE-07 не является частью этого коммита.

Следующий серверный пакет — BE-P2 (BE-07/08/09). Личная главная/мои встречи,
участие/решения, обсуждение и административные события/направления/аватары/
аккаунты пока не объявлены готовыми. Жалобы, личные SVG, демосброс, помощник,
печатное приглашение и QA/DELIVERY также остаются в очереди. Следующие назначения
выполняются пакетами; эта интеграция сама не запускает другой чат/агента.
