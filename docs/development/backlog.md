# Начальная очередь разработки

Все задачи ниже **предложены и не назначены**. Таблица не означает запуска работ.
Координатор задаёт исполнителей и исходный коммит перед распределением.

| ID | Результат | Зависимости | Область |
| --- | --- | --- | --- |
| PLAN-01 | Шесть сценариев с ролями, правами, ошибками и критериями приёмки | Нет | `docs/product/` |
| ARCH-01 | Решение о структуре проекта, серверном стеке, авторизации и командах запуска | PLAN-01 | Архитектурное решение и корневая конфигурация |
| CONTRACT-01 | Контракт данных и операций; независимые статусы организации, публикации и участия | PLAN-01, ARCH-01 | `docs/contracts/`, будущие общие типы |
| UI-01 | Базовые компоненты и состояния по брендбуку | ARCH-01 | Будущий пакет UI, согласованный владелец |
| WEB-01 | Каталог, страница встречи и способы участия | CONTRACT-01, UI-01 | Будущее веб-приложение |
| API-01 | Операции шести сценариев и проверка прав | CONTRACT-01 | Будущий сервер |
| QA-01 | Проверка объединённого решения по шести сценариям | WEB-01, API-01 | Сценарии приёмки и будущие тесты |
| MOBILE-01 | Объём первой мобильной версии и правила общей логики с вебом | PLAN-01, CONTRACT-01 | Спецификация идеи команды |

После согласования контрактов WEB-01 и API-01 можно вести параллельно. UI-01
может идти параллельно работе над контрактами при закреплённой области файлов.
Проверки приёмки полезно описывать во время PLAN-01, а исполнять на интеграции.

Новые функции добавляются после целостного прохождения основных сценариев.
Дополнительные идеи и их техническая реализация оцениваются раздельно.
