# Модерация общего справочника

Все карточки — **запланированы, не назначены и не начаты**. Основание —
[DEC-07](../../product/activity-types.md), API 0.13.0. Один раздел назначается
отдельным поручением по [правилам очереди](README.md).

## BE-10 — Административные операции направлений

- Родительская область: CATALOG-01.
- Зависимости: BE-09.
- Владелец / исходный SHA / ветка: назначает координатор перед запуском.
- Область файлов: apps/api/internal/modules/activitytypes/review/**; SQL activity_types.sql и миграции только у назначенного владельца БД. Подключение обработчиков — через координатора.
- Результат: Очередь q/catalogStatus/курсор, решение/причина, исправление любого состояния. expectedName, свободное имя и атомарное исправление с одобрением. Счётчик всех встреч; фильтр adminListEvents.activityTypeId готов в BE-09.
- Приёмка и проверки: Обе ветки, безопасный повтор, устаревшая форма, конкурентные решения/имена, коллизия с seed/другим состоянием. USER запрещён. REJECTED используется в новом событии без новой проверки. Исправление видно во встречах, роли/публикация/участия не меняются. PostgreSQL/Compose, без слияния и алиасов.
- Операции контракта: adminListActivityTypes, adminGetActivityType, adminDecideActivityType, adminRenameActivityType; связанное чтение adminListEvents.
- Вне задачи: изменения интерфейса, объединение/удаление, пересмотр решения, независимая правка OpenAPI/общих зависимостей и публикация без поручения.

## FE-12 — Экран направлений и административные действия

- Родительская область: CATALOG-01.
- Зависимости: FE-11.
- Владелец / исходный SHA / ветка: назначает координатор перед запуском.
- Область файлов: apps/web/src/features/admin/activitytypes/**; общую навигацию/маршрут SCR-20 и новые общие тексты подключает координатор.
- Результат: SCR-20, список/фильтры, данные создателя/решения, связанные встречи, одобрить/исправить и одобрить/отказать с причиной/исправить имя. Одобрение справочника не изображается допуском публикации встречи.
- Приёмка и проверки: Фикстуры API 0.13.0, затем BE-10 через Compose. Ошибки expectedName/коллизии не теряют ввод и не дают ложный успех. Все состояния/пустота/загрузка, телефон/клавиатура, закрытый маршрут, отсутствие кнопок слияния/пересмотра. После чтения статус виден автору встречи, имя изменяется в связанных карточках.
- Операции контракта: adminListActivityTypes, adminGetActivityType, adminDecideActivityType, adminRenameActivityType, adminListEvents; повторное чтение getEvent/listActivityTypes.
- Вне задачи: переписывание чужих страниц, объединение/алиасы, изменение общего контракта и публикация без поручения.
