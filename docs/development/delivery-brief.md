# Уточнения к сдаче и защите

Источник — ответы пользователя от **20 октября 2026**, DEC-24. Первичные PDF
не изменены; уточнения дополняют [комплект сдачи](../product/acceptance.md).

## Подтверждено

| Условие | Что учитываем |
| --- | --- |
| Последний коммит и презентация до 23:00 | 20 октября 2026, Asia/Krasnoyarsk, GMT+7. Финальную фиксацию и презентацию берёт пользователь |
| Защита командой, 8 минут с презентацией | Показ и объяснение в общем регламенте; отдельное время на вопросы не подтверждено |
| Машина предоставлена, интернет есть | Это не подтверждает внешний адрес или уже выполненное развёртывание |
| GitVerse настроен для команды/организаторов | Повторную настройку репозитория и доступов не планируем и не запрашиваем |
| Популяризация спорта, включая старшее поколение | Понятный первый шаг, условия встречи, запись и личные планы |
| Демодоступы | `/demo`, `/demo/accounts.txt`, выбор с подстановкой; обычная серверная проверка пароля |

Контейнеры по DEC-04 разворачивает пользователь. DELIVERY-01B требует фактического
адреса: прототип, Swagger и демодоступы должны открываться с машины эксперта.
Доступ к репозиторию не заменяет этот результат. Окончательные функции и ограничения
фиксируются после проверки, не выводятся из наличия экрана/данных.

## Акцент продукта и интерфейса

Ценность: **помочь человеку начать заниматься спортом вместе с людьми рядом с домом**,
даже без опыта и привычки пользоваться цифровыми сервисами. Спорт остаётся основой;
неспортивное развитие — отдельная идея. Старшее поколение — важная часть аудитории,
без возрастного ограничения регистрации.

Для FE/QA это уточняет обязательную доступность A-P05 / R6.7:

- До записи видны время с зоной, точное место, подготовка/инвентарь и способ присоединиться.
  Если сведений недостаточно, доступен вопрос в обсуждении.
- Кнопки называют действие. Подтверждённая запись и ожидание решения различаются текстом, не только цветом.
- Ближайшие подтверждённые встречи на главной по DEC-14; ожидающая заявка не выдаётся за запись.
- Сохраняем брендбук: основной текст 16/24 px, управление 48 px. Проверяем клавиатуру,
  видимый фокус, масштаб 200%, отсутствие обрезания текста/горизонтальной прокрутки.
- Примеры показывают разные виды спорта и опыт: зарядка, шахматы, бег, футбол.
  Не приписываем встрече медицинские гарантии или сведения, которых организатор не указал.

Новые поля возраста/здоровья, отдельный возрастной режим, рейтинги доверия и
дополнительную верификацию этими ответами не согласовали.

## Предлагаемый порядок показа в 8 минут

Опора для команды; саму презентацию готовит пользователь.

| Время | Содержание |
| --- | --- |
| 0:00–0:40 | Аудитория и трудность начать занятия одному |
| 0:40–1:20 | Понятный первый шаг и условия встречи |
| 1:20–5:20 | Пользователь, организация, администратор; оба режима записи и реальные аккаунты |
| 5:20–6:20 | Архитектура, хранение, контейнеры и Swagger |
| 6:20–7:00 | Проверенные улучшения, ограничения, развитие |
| 7:00–8:00 | Резерв на переключения, вопросы и завершение |

Перед защитой прогнать итоговый коммит с таймером, выбрать сохранившиеся контрольные
встречи и распределить реплики/переключения в команде. Пока API встреч отсутствует,
это план показа, не подтверждение S1–S6. Текущий статус —
[в отчёте интеграции](integration/2026-10-20/README.md).
