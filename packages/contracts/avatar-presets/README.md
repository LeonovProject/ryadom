# Готовые аватары

По поручению пользователя 20 октября 2026 добавлены шесть рисунков из
`/home/evgen/Documents/good_avatars`. Каталог содержит семь вариантов:
«Спутник», «Капитан», «Космонавтка», «Диджей», «Пожарная», «Вратарь», «Волшебник».
Единый источник ID/подписей/URL — [avatar-presets.json](../avatar-presets.json).
Прежний ID `ryadom-companion` и его изображение сохранены для существующих аккаунтов.

Регистрация показывает «Выберите аватар» и один раз случайно предвыбирает
вариант после получения непустого каталога. Ручной выбор и обновление каталога
не запускают новый случайный выбор. После отказа сервера/ошибки изображения
нужен доступный вариант; пустой каталог по-прежнему блокирует регистрацию.
`presetId` сохраняется в прежнем единственном register, API/БД не меняются.

## Подготовка файлов

Исходные иллюстрации используют title/desc/ARIA и clipPath вне профиля SVG 1.0.0.
`prepare.py` переводит круговую обрезку в пересечения векторных контуров и
сохраняет градиенты/обводки. Метаданные убраны; названия задаёт manifest.
Изображения остаются SVG, без встроенного растра, скриптов или внешних ресурсов.
Общий валидатор и его профиль не расширялись. Это одноразовый инструмент
для предоставленных исходников, не замена серверной проверки загрузок.

Временные инструменты подготовки: Python, `fonttools==4.67.0`,
`skia-pathops==0.9.2`; они не добавлены в зависимости приложения/образов.
Воспроизведение из корня после установки этих инструментов в отдельный venv:

```sh
python packages/contracts/avatar-presets/prepare.py /path/to/good_avatars packages/contracts/avatar-presets
```

После подготовки обязательно выполнить серверный `checksvg` из `apps/api`
на всех `../../packages/contracts/avatar-presets/*.svg` в закреплённой Go-среде
и сравнить вид с оригиналами. Все семь файлов прошли общий валидатор.
Файлы включаются существующими Dockerfile в API manifest и web assets.
Изменение каталога требует пересборки обоих образов.
